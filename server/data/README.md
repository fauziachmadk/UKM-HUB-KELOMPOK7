# Dataset - bagian Djalil

Penanggung jawab: Muhammad Aditya Djalil - 102022300225.
Mulai pekerjaan pada ukm.json; seluruh dataset merupakan bagian Djalil sampai
akhir array. JSON tidak boleh diisi komentar BEGIN/END atau tanda //.

Seed awal: 5 UKM contoh (satu tiap bidang) agar integrasi dapat dijalankan.
Tugas: kembangkan minimal 12 (target 15), id unik, kategori sesuai kontrak,
bool/int asli, berdiri ISO 8601, path logo aset valid. Pertahankan field singkat,
deskripsi/kegiatan supaya detail dapat dijelaskan. Hindari data pribadi nyata.

Jalankan dart test dari server setelah edit. Tambahkan tes kelengkapan dataset
dan filter. Peta sumber di docs/OWNERSHIP.md dibuat setelah formatting.
