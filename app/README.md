# Package Flutter UKM Hub

Buka root kelompok (satu tingkat di atas app) untuk panduan lengkap:
[README](../README.md), [mulai menjalankan](../docs/START_HERE.md),
[tugas anggota](../docs/TASKS.md), [batas kode/baris](../docs/OWNERSHIP.md).

Penanggung jawab fondasi/platform: Fauzi. UI Azka/Vanesa dan service/test Arief
memiliki BEGIN/END di lib/test. Native/platform hasil flutter create tidak perlu
diubah anggota layar. Lokasi sumber boleh di drive C atau D.

Jalankan flutter pub get/analyze/test/run dari folder app ini. Server berjalan
di terminal terpisah dari folder server. Fondasi bisa dijalankan tetapi belum
fitur UTS final; lihat status 28 poin pada README root.
